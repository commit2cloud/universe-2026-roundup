The big picture

GitHub's Universe message: connect the work from idea to completed software. The announcements extend agent orchestration, shared context, security, and delivery infrastructure while adding controls for administrators.

  • 01 / BUILDCoordinate agent workProjects, Fusion, and sessions that move across tools.
  • 02 / AUTOMATEMake it repeatableShared workflows, learning loops, and deeper reviews.
  • 03 / PROTECTFocus security effortReachability, AI scanning, and broader secret detection.
  • 04 / GOVERNPlan the rolloutEnterprise access, budgets, policies, and compute changes.

Announcement does not mean enabled everywhere. GA means generally available; previews and experimental features may change. Plans, administrator policies, client versions, regions, and usage charges still apply. GitHub Enterprise Server availability is not implied.

Labels reflect the announcement's stated release stage, with later corrections noted. In particular, the Moderate role became available Nov 12, and the cloud-sandbox post now specifies billing begins Nov 23. Use the linked documentation for current eligibility and terms.

01

Copilot & models

  • Public previewOct 28

    Copilot app: projects and computer use

    Projects bring repositories, context, agents, and results into one place for work that spans sessions or repositories. Computer use lets Copilot interact with desktop applications on macOS and Windows.

    Projects and app computer use were announced in public preview. Computer use requires approval for each app and can be disabled through organizational policy.

  • Generally availableOct 28

    Copilot Fusion: model routing and orchestration

    Choose Standard, High, or Max effort instead of managing every model choice. Fusion selects models and execution patterns for the task, including multi-model workflows when appropriate.

    Available in VS Code, Copilot app, CLI, and JetBrains. Model policies still apply; usage is charged for the models used. Higher effort is not a fixed-price entitlement.

    Read the Fusion documentation
  • Generally availableOct 28

    One cloud session across Copilot surfaces

    Start and continue the same cloud session across the web, Mobile, app, CLI, and VS Code, with Slack and Teams entry points. Resumable cloud sandboxes keep work independent of your laptop.

    Paid Copilot plans; rollout and cloud policies apply. The included Actions entitlement becomes a shared, dollar-based compute pool, also covering larger runners on Team and Enterprise Cloud. Cloud-sandbox billing begins Nov 23, 2026, per the Nov 19 update.

    Read about cloud sandboxes
  • Mixed availabilityOct 28

    GitHub intelligence: memory, dreaming, and code search

    Copilot can reuse preferences and repository conventions across sessions, propose improvements to its guidance, and find relevant code beyond the local checkout.

    Memory is GA on paid Copilot plans. Dreaming is opt-in public preview and consumes AI credits; changes to checked-in skills and instructions are proposed through pull requests. Availability varies by capability.

  • Experimental previewOct 28

    Fusion can route work to local models

    Opt in to routing between supported on-device and cloud models. Managed Windows setup supports MAI Code 1.1 Flash; CLI also supports eligible manually configured models across operating systems.

    Announced as experimental preview; current docs describe public preview with experimental settings required. Supported hardware and client setup vary. Local inference does not make the session offline: routing still uses the cloud.

    Check local-model requirements
  • Public previewOct 28

    Generate and edit images in Copilot

    Create or revise visual assets in natural language, preview them in the conversation, and save them to your workspace without moving to a separate image tool.

    Announced for VS Code, Copilot app, and CLI on eligible paid plans. Image generation is billed separately from the chat model through AI credits and is subject to model policy.

  • GA / gradual rolloutOct 26

    GPT-6.1 Terra joins Copilot

    OpenAI's GPT-6.1 Terra adds another model choice for everyday agentic coding and terminal work across supported Copilot clients.

    Available on Copilot Pro, Pro+, Max, Business, and Enterprise, with gradual rollout. Administrators control access through model policies; usage-based billing applies.

02

Automation & review

  • Rolling outOct 28

    Shared Copilot Automations

    Build cloud workflows that belong to the repository rather than one person. Teams can maintain them together, and GitHub actions are attributed to Copilot.

    AI credits are billed to the repository owner. Organization-owned repositories require an administrator to enable organization-billed cloud agent use. Availability is rolling out across paid Copilot plans.

  • Feature updateOct 28

    More automation triggers, tools, and cost controls

    Trigger workflows through the REST API, respond to more GitHub events, chain automations, and connect selected MCP tools. Set AI-credit limits per run, day, week, or month.

    The announcement adds 24 GitHub triggers and 20 GitHub tools. Paid Copilot plans and repository write access are required; you choose the tools an automation may use.

  • Feature updateOct 28

    Automations learn from their outcomes

    Use signals such as accepted review comments, changed labels, and merged pull requests to propose improvements to an automation's instructions and configuration.

    Proposed changes come to you for review and approval before being applied. This is not permission for an automation to silently rewrite its own operating rules.

  • Feature updateOct 28

    Manage cloud automations from VS Code

    Create personal or shared cloud automations from the Agents window, including event-driven and scheduled workflows that continue when your editor is closed.

    The announcement requires VS Code 1.144 and the cloud-automations setting to be enabled. Available with paid Copilot plans.

  • Feature updateOct 28

    Agent Merge watches and fixes pull requests

    Use "Watch and fix" on GitHub to have Copilot address selected blockers, including failing Actions workflows and merge conflicts, in a cloud environment.

    Available on paid Copilot plans, subject to policy. Auto-merge is a separate choice; GitHub still enforces the pull request's merge requirements.

  • GA + public previewOct 28

    Code review Max and Copilot approvals

    Max uses multiple review agents for deeper analysis of higher-risk changes. Copilot approvals can count toward required pull request approvals when administrators enable them.

    Max was announced in public preview; approvals are GA and off by default. Max uses more time and AI credits. Administrators can cap review effort and restrict approval paths.

    Read the code review documentation
  • Generally availableOct 28

    GitHub Agentic Workflows

    Define reasoning-based automation in Markdown and compile it into GitHub Actions workflows. Use existing runner infrastructure for tasks such as triage, CI investigation, documentation, and tests.

    This open-source GitHub Next project is distinct from Copilot Automations. GA on github.com for Free, Team, and Enterprise; the default Copilot CLI engine requires a Copilot license.

03

Security

  • Public previewOct 28

    Dependabot reachability analysis

    See whether your application has a call path to vulnerable dependency code. Verdicts and call-path evidence help teams prioritize fixes alongside severity and other risk signals.

    Preview for JavaScript and TypeScript on Enterprise Cloud, including data residency. Requires a supported lockfile and Dependabot alerts. Free during preview; "unreachable" is not a guarantee of safety or a reason to dismiss an alert automatically.

    Read requirements and limitations
  • Public previewOct 28

    AI Scan for entire repositories

    Run an on-demand scan of the default branch to find potential vulnerabilities beyond pull request changes. Findings join the code-scanning backlog alongside CodeQL alerts.

    Consumes Code Security AI credits; no Copilot license is required. Private or internal organization repositories require Code Security or Advanced Security. Private personal repositories are not supported.

    Compare AI Scan capabilities
  • Public previewOct 28

    Code scanning for AI applications and agents

    Identify AI-specific risks in pull requests, with an initial focus on indirect prompt injection and risky paths from untrusted content to models with access to tools or data.

    The announcement describes expanding coverage for sensitive information disclosure and excessive agency. Preview requires Advanced Security on github.com; not available on Enterprise Server.

    Read about AI application scanning
  • Public previewOct 28

    Push protection for AI-detected secrets

    Block potential secrets that lack a recognized token format by evaluating how values are used in surrounding code, alongside existing pattern-based detection.

    Off by default. Requires Secret Protection or Advanced Security on github.com, plus enabled AI-detected secret scanning and push protection. AI detection in the push path consumes AI credits from enablement.

  • Generally availableOct 28

    Public monitoring for enterprise secrets

    Receive alerts when secrets attributed to your enterprise appear in public GitHub content, including locations outside repositories your organization owns.

    Included with Secret Protection or Advanced Security for Enterprise Cloud, including data residency. Enable it from the enterprise Security tab. Public monitoring does not scan other users' private repositories.

  • Public previewOct 28

    Security extension for the Copilot app

    Browse code-scanning alerts, ask Copilot to explain or help fix them, and review local changes for security issues from one app surface.

    Alert access follows repository permissions; private repositories need Code Security. Explain, Fix, and security-review prompts consume AI credits. Fixes stay local until you review and push them.

04

Developer experience

  • Mixed availabilityOct 28

    VS Code: connected and remote agent work

    The Universe update brings cloud-session continuity, an Agent Host independent of editor windows, remote agent execution, and an open Agent Host Protocol for custom clients.

    Also includes side-by-side model comparison and a customization marketplace in preview, plus experimental computer use. Local and remote hosts must remain running for work hosted on those machines.

  • GA + rolloutOct 28

    JetBrains: Fusion, sandboxing, and next edits

    Copilot Fusion brings model orchestration to JetBrains, alongside generally available local sandboxes and next edit suggestions. Session and settings improvements round out the update.

    Fusion rolls out gradually. Update the Copilot plugin and review sandbox and permission settings before introducing agent workflows to your team.

  • Public previewOct 28

    Connect once, use tools across Copilot

    GitHub-verified MCP connectors bring context from services such as Slack, Figma, Sentry, and Notion into supported Copilot experiences without repeating local setup.

    Rolling out in preview on all Copilot plans. Business and Enterprise require Editor preview features; MCP allowlists and each service's own administrator controls still apply.

  • Generally availableOct 26

    Assisted permissions

    An AI evaluation lets requests classified as clearly safe proceed automatically while sending other command, filesystem, or URL requests to you for approval.

    GA in Copilot CLI, app, and VS Code. Enterprises can manage Assisted and Allow All separately and choose the default mode. Assisted is not the same as unrestricted execution.

  • Generally availableOct 28

    Repository plugin defaults and enterprise controls

    Recommend and enable plugins through trusted repository defaults. Enterprise-managed settings can require or block plugins and limit installation to approved marketplaces.

    GA in VS Code, CLI, and app. Repository defaults are not enforcement; enterprise policy takes precedence. Managed controls require eligible Enterprise Cloud and Copilot licensing.

  • Open sourceOct 28

    Replica: design-system-aware prototyping

    GitHub Design open-sourced an AI prototyping tool that uses your team's components, patterns, and documentation to turn ideas into interactive prototypes in the Copilot app.

    Released under the MIT license. Teams can prototype locally or operate an optional self-hosted Replica Hub to share work and gather feedback.

05

Platform & collaboration

  • Public previewOct 28

    Issue artifacts

    Keep plans, research, links, and interactive HTML artifacts alongside the issue they support, with version history and shareable links. Manage artifacts on GitHub or through the GitHub CLI.

    Client support differs: the announcement says creating and viewing HTML artifacts in the Copilot app is coming later, even though github.com supports HTML artifacts.

  • GA / available Nov 12Oct 28

    A Moderate role for GitHub Issues

    Delegate issue editing, moderation, and metadata management without granting access to code. This separates community and issue-management responsibilities from code permissions.

    Announced Oct 28; the source was updated Nov 12 to confirm availability. Transferring an issue requires Moderate or higher on both repositories.

  • Feature updateOct 28

    Pull request limit exemptions

    Exempt established contributors from contribution caps using minimum account age or the number of pull requests already merged in the repository.

    Meeting either enabled rule grants an exemption. Repository-level cap settings override organization-level settings; individual exemption lists remain available.

06

Actions & infrastructure

  • Rolling changeOct 28

    Multi-cloud compute for Actions runners

    Eligible Linux jobs can use compute on AWS as well as Azure to expand capacity and improve resilience, without changing workflow syntax or runner labels.

    Applies to eligible 2-core and 4-core Linux runners, not Windows or specialized configurations. Automatic for Free, Pro, and Team; Enterprise Cloud can opt in. Review network allowlists against all published Actions ranges.

  • Generally availableOct 28

    Actions workflow dependency lockfiles

    Keep readable action tags in workflow files while executing locked commits, including transitive dependencies. Dependabot can update the matching lockfile entries with action updates.

    GA on Free, Team, and Enterprise Cloud, including data residency. Adoption can be gradual or policy-enforced. Locking a dependency does not establish that it is safe.

  • Network updateOct 29

    New webhook delivery IP ranges

    GitHub added webhook delivery ranges to the Meta API. Organizations with static inbound allowlists should update them to avoid rejecting legitimate deliveries.

    Applies to github.com across plans. If your allowlist already synchronizes with the Meta API's hooks field, no manual change is needed for these additions.

07

Enterprise & extensibility

  • Sales-assisted availabilityOct 28

    Copilot access through GitHub Enterprise

    Eligible Enterprise Cloud customers working with a GitHub or Microsoft account team can adopt a model that includes Copilot access for licensed Enterprise users without a separate Copilot subscription charge.

    Access is not free AI usage. This model includes no monthly AI-credit allowance; metered usage is billed from the first request. Activation and access assignment are required. Self-serve availability is staged; existing Business and Enterprise plans remain available.

    Check eligibility, activation, and budgets
  • Public previewOct 27

    Server-to-server Copilot authentication

    Organization-installed GitHub Apps can use installation tokens with the Copilot SDK, so services and agents no longer need to run under a signed-in individual's identity.

    Requires the Copilot Requests organization permission. Usage is attributed and billed to the installation's organization, with its model policies, budgets, and spending controls.

  • Transition announcedOct 28

    GitHub Copilot SDK becomes Microsoft Copilot SDK

    The SDK is evolving into the programmable interface for a shared Microsoft Copilot harness, while retaining developer control over prompts, tools, policies, and application experiences.

    Branding, repository, and documentation changes are phased. Existing package names and namespaces may remain during the transition; the announcement requires no immediate changes from existing users.
